# 🧬 CompBio & AI Structural Sandbox

A lightweight playground combining Python, open-source AI tooling, and programmatic 3D biological visualization.

## 📌 Vision & Scope
- **Interactive 3D Structure Viewer:** Fetch PDB atomic coordinates and render interactive protein ribbons dynamically via `py3Dmol`.
- **Gene Network Graphs:** Render interactive 2D interaction networks using `Pyvis` / `Plotly`.
- **AI Agent Integration:** (Future) Query biological databases (UniProt / PubMed) autonomously to generate target reports.

## 🚀 Quickstart
```bash
pip install py3Dmol rdkit-pypi pyvis plotly
